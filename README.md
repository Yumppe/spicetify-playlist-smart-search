# Playlist Smart Search

A Spicetify extension that improves playlist search with smarter filtering and advanced query syntax.

![Playlist Smart Search](preview.png)

## Features

- Search directly inside Spotify playlists
- Filter by track title, artist, album, and release year
- Combine multiple conditions
- Exclude unwanted matches
- Search exact artists
- Use year ranges and comparisons
- Designed to work well with large playlists
- Integrates with Spotify's playlist interface
- Includes compatibility fallbacks for different Spotify layouts
- No telemetry or remote logging

## Search syntax

Normal text searches across the available track information.

You can also use more specific filters:

```text
artist:radiohead
title:creep
album:parachutes
year:2020
